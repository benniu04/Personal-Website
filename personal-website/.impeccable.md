# Impeccable Design Context

## Design Context

### Users
Recruiters, hiring managers, and fellow builders evaluating Ben Niu — a CS & Finance student at
Northeastern building full-stack products and exploring fintech. They should be able to *play*
the site or skim it: the 3D world rewards exploration, the 2D journey and panels keep every fact
one interaction away.

### Concept
**Pixel Odyssey** — the site is an indie game about Ben's life, in two forms sharing one visual
language:
- `/` — an explorable 3D voxel world (three.js / @react-three/fiber): drive a tiny voxel Ben
  down a winding path from a Connecticut trailhead through Boston, three co-op "levels", a
  side-quest arcade, a rest stop (playable piano, tennis ball with real physics, golf), the
  hardware rig, a quest-log monument, to a campfire save point. Walk up + press E (or click)
  to open story panels carrying the real content.
- `/journey` — a 2D scroll journey through the same 10 chapters (canvas pixel scenes, scroll-
  walking avatar, parallax). It is the automatic fallback (no WebGL, reduced motion) and the
  "prefer scrolling?" option, always one click away.

### Brand Personality
Warm, cozy, handcrafted — Stardew Valley / A Short Hike energy wearing a well-set print
aesthetic. Playful surface, meticulous underneath: "this person sweats the details, and had fun."

### Aesthetic Direction
- **Palette**: unchanged brand tokens — cream #F6EBE0, blush #F1DFD1, parchment #FBF5EE, ink
  #43261A, cocoa #5F4037, clay #8F6A58, rust #A24A21 (+deep/ember), linen #EEDFD1, plus game
  accents defined once in `src/pixel/palette.js` (foliage greens, flame amber, warm white, skin).
  NO dark neon, NO cyan, NO glassmorphism.
- **Type**: Sentient light serif for display; Schibsted Grotesk body; Spline Sans Mono labels;
  **Silkscreen** (`font-pixel`) for game-UI chrome — HUD chips, chapter labels, buttons.
- **Pixel system**: all art is programmatic. String-array sprite maps (`src/pixel/sprites.js`)
  render 2D via canvas blitting (`drawSprite`) and extrude into 3D voxel models
  (`src/world/voxel.js` → InstancedMesh). One sprite, both worlds.
- **UI kit** (`src/index.css`): `.pixel-panel` (parchment, 3px notched-corner ink border, hard
  offset shadow), `.pixel-btn-*` (chunky press-down buttons), stepped `steps()` animations only.
- **Signature moves**: dialog-box panels for all reading; PixelMark identicons per project;
  live GitHub heatmap as "quest log"; locked-level treatment for future roles; the campfire
  save point as contact.

### Design Principles
1. Text never sits on art — every paragraph lives on a parchment panel.
2. One palette everywhere: world, sprites, UI all draw from the same ~20 colors.
3. Native scroll and native controls; no scroll-jacking, no camera that fights the player.
4. Game chrome is pixel-stepped (Silkscreen, steps() easing, hard shadows); prose stays serif/sans.
5. Every layer degrades: 3D → 2D journey → static reduced-motion paintings; content identical.
6. Real content is sacred: every fact from the resume/pages survives in both experiences.
